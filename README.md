# CorvaUI Svelte Demo

Public Vercel showcase using SvelteKit, direct `@corvaui/web-components` custom elements, `@corvaui/tokens`, and the Amber token family. Common Ground Energy is a four-route community microgrid site with marketing, program comparison, a site DataGrid, and impact reports.

## Routes

- `/` clinic operations launch surface
- `/dashboard` clinic access dashboard
- `/work-orders` visit intake
- `/customers` patient records
- `/data-table` sortable/filterable schedule grid
- `/settings` clinic workspace settings
- `/about` package proof

## Quality Gate

Run `npm test` to audit dependencies and build the production bundle.
